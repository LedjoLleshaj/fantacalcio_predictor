# fbref manual export checklist — Serie A (comps/11)

Each URL = one fbref page holding the PLAYER table + SQUAD (for) + SQUAD (vs against) tables.
On each page: 'Share & Export' -> 'Get table as CSV' (or copy). Save under fbref_data/ per the scraper's filenames.

Scraper expects these CSVs per season dir:
  outfield_players.csv, keepers_players.csv, teams.csv, teams_vs.csv
  (outfield_players = concat of the 8 outfield categories' PLAYER tables;
   keepers_players  = concat of keepers + keepersadv PLAYER tables;
   teams / teams_vs = SQUAD for / against tables across all categories.)
Dirs: current -> fbref_data/  |  2025-2026 -> fbref_data/season2526/  |  2024-2025 -> fbref_data/season2425/
